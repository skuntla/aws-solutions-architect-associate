01 / Storage

S3 storage classes — the 0 / 30 / 90 / 180 rule

Choose by access frequency + retrieval speed + retention duration + resilience, not by storage price alone.

Practice question: Intermediate analytics results retained 24 hours and read repeatedly → S3 Standard. Standard-IA charges a 30-day minimum plus retrieval; Glacier Instant a 90-day minimum plus retrieval.

Lifecycle

Transition older data to suitable tiers or expire it with lifecycle rules. Rules operate on a day basis; deletion is not guaranteed at the exact 24-hour mark.

EBS vs EFS vs S3

EBS: EC2 block volume, AZ-scoped. EFS: shared NFS filesystem for Linux, regional mount targets. S3: object storage via API, not normal POSIX disks.

Instance store

High-performance temporary local storage. Ephemeral: not suitable for persistent state across instance loss.

02 / Databases

Relational databases, replicas and connection pooling

Aurora writer

Writes

Primary writer executes INSERT/UPDATE/DELETE. More application servers do not automatically increase writer throughput.

Aurora read replicas

Scale reads

Offload SELECT queries from the writer. A read replica does not accept normal application writes. Replication can lag.

RDS Proxy

Connection pooling

Applications connect to the proxy; it keeps/reuses a smaller pool of actual database connections. Helps with spikes in connections, not inherently faster SQL writes.

Aurora Global Database

Cross-Region

Provides cross-Region replication of an Aurora database for global reads/disaster recovery. Replication is at the database-cluster level, not selective per table.

DynamoDB Global Tables

Multi-Region

Multi-Region replicated DynamoDB tables for globally distributed workloads. Moving an existing Aurora SQL app to DynamoDB may require substantial refactoring.

ElastiCache

Fast repeat reads

Cache hot data such as catalog details, frequently accessed query results and sessions. A cache is not a default durable purchase-transaction queue.

RDS Proxy: exact 10 vs 15 example

If the proxy's 10 database connections are all busy and 15 requests need them, 5 can wait temporarily for a free connection. If they wait longer than ConnectionBorrowTimeout, they fail. As earlier transactions finish, their connections are reused by waiting requests. It is not a durable queue and does not raise Aurora's intrinsic write capacity.

Exam nuance: If Aurora's write CPU is saturated, neither RDS Proxy nor extra EC2 instances solves the root write bottleneck. Diagnose connections vs queries vs application capacity.

Global gaming application scenario

Requirement: global games reference data, but users and games_played must remain regional; minimize changes from Aurora. Consider Aurora Global Database for a dedicated games database and regional Aurora databases for regional tables. Global Database replicates a whole database cluster—not a single table inside a shared cluster. Splitting tables into separate databases/clusters may itself require migration/refactoring.

Ticket purchase architecture

Users → application/API → SQS (buffer purchase jobs) → EC2 Auto Scaling workers → RDS Proxy (pool DB connections) → Aurora writer (commit transaction).

For actual sales, design idempotency, seat reservation/expiry, ordering, capacity limits, failure handling, and user confirmation carefully. SQS Standard can deliver duplicate or out-of-order messages.

04 / Security

IAM and security fast decisions

IAM evaluation

Explicit deny wins over allow. Without applicable allow, default deny. Identity- and resource-based policies interact with SCPs and permission boundaries.

Role vs user vs group

Role: assumed temporary credentials, ideal for EC2/Lambda. User: identity. Group: policies for users, not assumable.

Security Group vs NACL

SG: stateful, allow rules at ENI. NACL: stateless, allow and deny rules at subnet boundary, evaluated in rule-number order.

KMS vs Secrets Manager

KMS: manage cryptographic keys and encryption operations. Secrets Manager: store and rotate passwords/API secrets.

CloudTrail / CloudWatch / Config

CloudTrail: API activity/audit. CloudWatch: metrics/logs/alarms. Config: resource configuration history/compliance.

Organizations / SCP

Service control policies set account/OU permission ceilings; they do not grant permissions. Explicit deny overrides allowed actions.

05 / Networking

Networking, compute and delivery

ALB / NLB / GWLB

ALB: HTTP/HTTPS, path/host routing. NLB: L4 TCP/UDP/TLS, very high performance/static IP. GWLB: transparent third-party network appliances.

NAT Gateway / Internet Gateway

IGW: path for internet-routable public resources. NAT Gateway: lets private-subnet instances initiate outbound internet access via a public NAT gateway.

VPC endpoints

Gateway: S3 and DynamoDB. Interface: PrivateLink to many AWS services through ENIs; typically per-hour and data charges.

Route 53

Weighted = traffic splitting; latency = lowest measured latency; failover = health-check based active/passive; geolocation = location-based routing.

Fargate vs EC2 launch type

Fargate: serverless container compute; no EC2 host management. EC2: manage underlying instances; more host-level control.

CloudFormation vs Beanstalk

CloudFormation: infrastructure as code. Elastic Beanstalk: managed app deployment environment that provisions underlying resources.

Cost clue: “Most cost-effective” means total cost, including retrieval, minimum storage duration, transfer and operational complexity—not just the lowest advertised storage price.
07 / Practice

Rapid recall: open one answer at a time

Analytics staging data accessed often, deleted after 24 hours. Which S3 class?

S3 Standard. No minimum duration or per-GB retrieval fee. IA and Glacier minimums penalize short-lived data.

Aurora has thousands of idle client connections. What helps?

RDS Proxy. Reuses and multiplexes database connections. It does not accelerate SQL execution.

Flash sale produces bursts of purchases that can be processed asynchronously. What helps?

SQS + scalable workers. Buffers work durably; consumers process as capacity allows. Design for idempotency and seat consistency.

SQL queries are 95% reads. The writer is overwhelmed. What helps?

Read replicas and routing read traffic to them, if eventual-consistency constraints allow.

Important archive, rarely retrieved, but retrieval must be immediate?

Glacier Instant Retrieval can fit when stored long enough to justify its 90-day minimum and retrieval pricing.

Explicit IAM deny conflicts with an allow. Who wins?

Explicit deny.

Need to distribute HTTP traffic based on path?

Application Load Balancer (ALB).
