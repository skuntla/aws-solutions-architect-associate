CloudWatch, CloudTrail and Config

Monitoring metrics and alarms, API audit events, configuration history.

When to use

CloudWatch detects CPU alarms. CloudTrail audits API calls. Config tracks resource configurations and compliance.

Simple example

Find who changed an IAM policy: CloudTrail.

Common exam trap

CloudWatch metrics are not a replacement for API audit events.
