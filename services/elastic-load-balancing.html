Elastic Load Balancing

Distributes incoming requests across targets using different layer capabilities.

When should I use it?

ALB for HTTP/HTTPS host/path routing; NLB for high-performance L4 traffic; GWLB for transparent network appliances.

Simple example

Route /api requests to one target group and /images to another → ALB.

Common exam trap

ALB, NLB and GWLB do different jobs; don't select GWLB as a normal web load balancer.

Exam decision rule

Identify the exact requirement, determine which bottleneck or constraint the service addresses, and eliminate answers that solve a different problem. Cost, latency, resilience and application-refactoring constraints can change the right choice.
