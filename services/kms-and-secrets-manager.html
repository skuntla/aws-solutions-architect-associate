security / SAA-C03

KMS and Secrets Manager

KMS manages cryptographic keys; Secrets Manager stores and rotates passwords and API secrets.

When to use

Use KMS to control encryption keys. Use Secrets Manager for application credentials and automated rotation.

Simple example

Aurora credentials rotated by Secrets Manager.

Common exam trap

KMS is not a credentials vault.

Unofficial notes. Verify details at AWS docs.
